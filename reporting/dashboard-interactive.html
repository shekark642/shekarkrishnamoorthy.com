Interactive Explorer — Light Server Query, Client Computes

The server does the minimum work here: a filtered, bounded GET /api/events query. Everything after that — the summary stats, the expandable rows — is computed and rendered in the browser from the raw rows.

Not locked to the collector's own event types or fields: type any type string this table has ever stored (blank = all), and any dot-path into the payload to compute min/max/avg on — works for whatever kind of data ends up here later, not just page-load beacons. Before rendering, this page checks the response size against a threshold and refuses to render (rather than freezing the tab) if it's too big — try a small limit first.
