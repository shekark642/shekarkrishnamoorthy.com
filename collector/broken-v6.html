HW3 — Module 07: Intentionally Broken Page

This page fires real, unprompted errors as soon as it loads — no button clicks required — to show collector-v6.js catching what a real user would never report:

  • An uncaught ReferenceError from a bad global reference
  • An unhandled promise rejection from a failed fetch
  • A 404 image (resource load failure)
  • A 404 script (resource load failure)

Open the console to see each [collector-v6] error payload: log, or check /test-v6.html for a live visual log.
