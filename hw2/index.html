Homework 2

Five example types, in three languages: NodeJS (Express), Python, and C. Perl versions of the same demos were provided by the course as a reference and are not part of this assignment's graded set.

Start here: the shared Echo Form — pick a language, HTTP method (GET/POST/PUT/DELETE), and encoding (x-www-form-urlencoded or JSON), then submit to see any of the three echo endpoints below respond live via vanilla JavaScript. It also works with JavaScript off, in a reduced GET/POST-only mode.

NodeJS Express

Runs as a persistent Express process (systemd user service), reverse-proxied by Apache — not one-shot CGI like the other two languages.

  • hello-html-nodejs HTML greeting + timestamp + IP
  • hello-json-nodejs same, as JSON
  • environment-nodejs request headers (Express's env-equivalent)
  • echo-nodejs echo backend — use the form above
  • state-nodejs server-side session (in-memory, cookie-based)

Python CGI

Runs as one-shot CGI scripts under Apache's mod_cgid, same execution model as the reference Perl demos.

  • hello-html-python HTML greeting + timestamp + IP
  • hello-json-python same, as JSON
  • environment-python CGI environment variables
  • echo-python echo backend — use the form above
  • state-python server-side session (file-based, cookie ID)

C CGI

Compiled from source on every deploy and run as one-shot CGI binaries under mod_cgid, no external libraries.

  • hello-html-c HTML greeting + timestamp + IP
  • hello-json-c same, as JSON
  • environment-c CGI environment variables
  • echo-c echo backend — use the form above
  • state-c server-side session (file-based, cookie ID)
